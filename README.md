# test-cli

Generated by **slskit init**.

- Runtime: typescript
- Framework: AWS SAM
- Database: prisma
- API Gateway: yes (each service owns an HTTP API in its own template)
- Common layer: yes (src/shared attached to every function)
- Function memory: 128 MB

See `slskit.json` for the full project graph.

## Layout

Every service owns a `template.yaml` next to its handlers, so services can be
deployed one at a time. The root `template.yaml` pulls them all together.

```text
test-cli/
├── src/
│   ├── functions/
│   │   ├── auth/
│   │   │   ├── template.yaml
│   │   │   ├── login/handler.ts
│   │   │   └── register/handler.ts
│   │   └── product/
│   │       ├── template.yaml
│   │       ├── getProducts/handler.ts
│   │       └── createProduct/handler.ts
│   ├── services/
│   │   ├── auth/login.ts
│   │   └── product/getProducts.ts
│   └── shared/
│   │   └── logger.js
│   │   └── db.ts
├── template.yaml         (root stack)
├── .env.dev              (the "dev" environment's values, gitignored)
├── package.json
├── slskit.json
└── README.md
```

Each function delegates to a matching service module: `src/functions/auth/login`
calls `src/services/auth/login`.

## Environments

The project starts with one environment, `dev`, and its values live in
`.env.dev`. Add more as you need them -- each one gets its own file,
its own CloudFormation stack, and its own `APP_ENVIRONMENT`.

```bash
slskit env list
slskit env add production --profile prod-admin --region eu-west-2
slskit env set LOG_LEVEL=debug
```

## Prisma

Point `DATABASE_URL` in `.env.dev` at your database, then:

```bash
npm run prisma:migrate    # create and apply a migration (development)
npm run prisma:generate   # regenerate the client after editing schema.prisma
npm run prisma:studio     # browse the data
```

Deployments apply already-created migrations instead:

```bash
npm run prisma:deploy
```

Those scripts read `.env.dev`. Run them against another
environment by naming its file:

```bash
npx dotenv -e .env.production -- npx prisma migrate deploy
```
